LitAmor - One Curated Match Per Day

Mobile App Relationship Design Emotional UX UI/UX

Live on Google Play Store

LitAmor is not just a concept project, it is published live on the Play Store.

Project Overview

LitAmor is a dating app built around slow, intentional matching. Instead of endless swiping, each user receives one highly compatible match per day, selected using profile information, preferences, and behavior signals. The experience is designed to reduce decision fatigue and encourage meaningful conversations.

Problem Statement

Most dating apps prioritize volume and rapid swiping, which often leads to shallow interactions and burnout. Users spend more time filtering than connecting. The challenge was to design a dating flow that removes swipe overload and delivers one high-quality match each day.

Goals

  • Deliver one strong, profile-based match per day.
  • Eliminate swipe mechanics and reduce cognitive overload.
  • Build trust with transparent compatibility cues.
  • Encourage meaningful chats over high-volume matching.

Target Users

  • Singles tired of swipe-heavy dating experiences.
  • People who value quality matches over match quantity.
  • Users looking for intentional, profile-driven dating.

Core UX Features

  1. Compatibility Onboarding: captures profile details and preferences used for daily matching.
  2. One Match Daily: users receive a single curated profile each day instead of a swipe feed.
  3. No-Swipe Interaction: clear actions to accept or pass, keeping decisions simple and intentional.
  4. Focused Messaging: chat opens only after mutual interest to support quality conversations.
  5. Premium Layer: deeper match insights and added visibility controls for serious users.

Design Decisions

Decision Reason
Soft, clean UI palette Build emotional safety and reduce stress while chatting
Prompt-assisted writing flow Helps users who do not know how to start expressing feelings
Simple navigation structure Keeps focus on communication instead of app complexity
Premium perks screen Creates clear upgrade value with transparent feature explanation

Usability Focus

  • Readable type scale and high contrast for comfort.
  • Low cognitive load in onboarding and writing flows.
  • Consistent component behavior across profile, messages, and settings.
  • Mobile-first spacing and touch-friendly controls.
